# Обогащение встроенных колод

`gen.py` добавляет к встроенным колодам Spark:

- **транскрипцию** (подсказка под словом), для русской колоды — транслитерацию с ударением;
- **пояснение и пример** с переводом (блок «Пояснение» под ответом);
- **звук произношения** — офлайн-синтез: английский и русский — [Piper](https://github.com/rhasspy/piper) (en-us-lessac, ru-irinia, релиз v0.0.2); испанский и немецкий — Coqui VITS (es-css10, de-thorsten, релизы v0.8.0_models / v0.7.0_models). `vits.py` делает до 16 вариантов каждого слова и берёт самый чистый (без лишних пауз и повторов), `screen.py` проверяет готовые клипы (длительность, начальные шипящие). Все mp3 колоды лежат одним файлом `<колода>.audio.mp3`, в JSON колоды — индекс `ключ → [смещение, длина]`. Ключ — первые 24 символа SHA-256 файла, как у остальных медиа Spark.

Тексты пояснений — в `data_*.py`. Запуск (после `make.py`, если он перегенерировал колоды):

```
python3 gen.py ../            # нужны piper_amd64/, voice-*/, модели VITS и ffmpeg; Python с coqui-tts — в VITS_PY
```

Скрипт идемпотентен: повторный запуск не дублирует звук и описания. После изменения колоды поднимается её `version` — у пользователей в каталоге появится кнопка «Обновить колоду», которая дополнит уже добавленные карточки, не трогая их правки.
