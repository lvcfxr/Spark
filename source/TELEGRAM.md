# Telegram

Настройка сервера и входа через Telegram — см. **SETUP.md**.
Бот: в @BotFather `/setmenubutton` → адрес сайта GitHub Pages (https). Картинки для бота — в `apps/desktop/brand/`.
Обновления: Claude присылает Pull request в репозиторий; после «Merge» GitHub Pages обновляет сайт, у открытых копий появляется кнопка «Обновить».
