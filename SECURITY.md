# Безопасность

Нашли уязвимость? Не публикуйте её в открытом issue. Напишите владельцу репозитория личным сообщением или через «Security → Report a vulnerability» на странице репозитория.

Что важно знать:
- В репозитории нет секретов. Ключ в `config.js` — публичный (роль `anon`); доступ к данным ограничен правилами базы (RLS) для каждого пользователя.
- Ключ `service_role`, токен бота и пароль администратора бота хранятся только в секретах Supabase и GitHub Actions.
- Приложение работает под политикой безопасности браузера (CSP): исполняется только собственный код, обращения — только к Supabase, Telegram и Wikimedia.
