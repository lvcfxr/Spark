# Spark

Карточки с интервальными повторениями для Telegram (Mini App). Сайт публикуется через GitHub Pages из ветки `main`.

В этом репозитории лежит только готовая публичная часть:

| Что | Для чего |
|---|---|
| `index.html`, `nsfw.js`, `icon-512.png`, `version.json`, `changelog.json` | собранное приложение и номер версии |
| `decks/`, `courses/`, `bot/` | каталог колод, курсы и картинки приветствия бота |
| `config.js` | адрес и **публичный** ключ сервера (anon): данные защищены правилами доступа на сервере |
| `.github/workflows/` | рассылка новостей и напоминаний ботом (секреты хранятся в настройках репозитория) |

Исходный код, схема базы и инструкции по настройке хранятся отдельно и в этот репозиторий не входят.
