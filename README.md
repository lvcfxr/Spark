# Spark — Telegram Mini App

Карточки с интервальными повторениями. Сайт публикуется через GitHub Pages из ветки `main`.

| Где | Что |
|---|---|
| `index.html`, `icon-512.png`, `version.json` | собранное приложение (один файл) и номер версии — по нему открытые копии предлагают обновиться |
| `decks/` | встроенный каталог колод Spark (можно пополнять без пересборки) |
| `config.js` | адрес и публичный ключ сервера синхронизации — заполняется один раз, патчи его не трогают |
| `setup/`, `SETUP.md` | настройка сервера (Supabase) и входа через Telegram |
| `source/` | исходный код: из него собираются патчи (`source/apps/desktop` → `npm run build`) |
| `.nojekyll` | GitHub Pages отдаёт файлы как есть |
