# Recall — Telegram Mini App

Статическая страница (Mini App) для Telegram. Публикуется через GitHub Pages из ветки `main`.

- `index.html` — приложение целиком (один файл)
- `config.js` — настройки сервера синхронизации (необязательно)
- `version.json` — версия: по ней приложение предлагает обновиться
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages
